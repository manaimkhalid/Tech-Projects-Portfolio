# Exploratory Data Analysis (EDA)

## Overview
This project explores the cleaned layoffs dataset using SQL to identify trends and patterns in company layoffs.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Skills Practiced
- Aggregate functions (SUM, MAX, MIN, AVG)
- GROUP BY and ORDER BY
- Common Table Expressions (CTEs)
- Window functions
- Ranking using DENSE_RANK()
- Rolling totals
- Data analysis by company, industry, country, and year
